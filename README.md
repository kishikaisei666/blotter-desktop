# Blotter

Личный офлайн-журнал сделок для Windows. Все данные хранятся только на вашем компьютере, без облака и регистрации.

Этот репозиторий содержит **только готовые версии программы** (исходный код здесь не публикуется).

## Скачать

Последняя версия: **[Releases → Latest](https://github.com/Awallon555/blotter-desktop/releases/latest)**

- `Blotter-Setup-<версия>.exe` — установщик (без прав администратора). Обновляется автоматически. Данные: `%APPDATA%\Blotter`.
- `Blotter-<версия>-portable.exe` — портативная версия, без установки. Данные хранятся в папке `data\` рядом с файлом. Сама не обновляется — программа сообщит о новой версии.

## Первый запуск: предупреждение Windows

Программа не подписана платным сертификатом, поэтому Windows может показать окно **«Система Windows защитила ваш компьютер»** (SmartScreen).
Нажмите **«Подробнее» → «Выполнить в любом случае»**.

Антивирус иногда ошибочно реагирует на неподписанные программы — в этом случае добавьте файл в исключения.
